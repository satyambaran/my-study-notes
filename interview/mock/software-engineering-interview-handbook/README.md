# Software Engineering Interview Handbook

A book-style interview preparation resource for backend, infrastructure,
distributed systems, platform, cloud, and production engineering roles.

## Reading Paths

- **Deep study:** Read the nine parts in order.
- **Interview refresh:** Start with `companions/last-minute-revision-guide.md`.
- **Coding rounds:** Use `companions/dsa-cheat-sheet.md`.
- **Design rounds:** Use `companions/system-design-cheat-sheet.md`.
- **Practice:** Use `companions/interview-qa-companion.md`.
